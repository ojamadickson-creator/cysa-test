# CySA+ CS0-004 Exam Simulator

## Quick Deploy to GitHub Pages

1. **Create a new public GitHub repository** (e.g., `cysa-exam`)
2. **Upload ALL files from this folder** directly to the repo root:
   - `index.html`
   - `css/style.css`
   - `js/questions.js`
   - `js/exam.js`
3. **Do NOT upload this folder as a subfolder.** The files must sit at the repo root.
4. Go to **Settings → Pages** in your repo
5. Source: **Deploy from a branch** → select `main` → folder `/ (root)`
6. Click **Save**
7. Wait 1–2 minutes, then visit `https://YOURUSERNAME.github.io/cysa-exam/`

## Troubleshooting 404
- Ensure `index.html` is visible at the repo root (not inside another folder)
- The repository must be **public** for free GitHub Pages
- If using a custom domain, add it in Settings → Pages after initial deploy works
